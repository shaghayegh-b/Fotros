# 🛍️ Fotros – Advanced Online Clothing Store

Fotros is a **feature-rich, modern online clothing store** developed as a **portfolio-level project** to demonstrate real-world front-end development skills using **React**, **Vite**, and **Tailwind CSS**.

This project goes beyond a simple shop UI and focuses on **application architecture, state management, UI/UX consistency, and scalability**, similar to what is expected in real production projects.

🔗 **Live Demo:** [https://shaghayegh-b.github.io/Fotros/](https://shaghayegh-b.github.io/Fotros/)

---

## ✨ Project Goals

* Build a **realistic e-commerce experience** using modern React practices
* Practice **scalable component-based architecture**
* Implement **global state management** with Context API
* Create a **clean, responsive, and theme-aware UI**
* Deliver a project suitable for **portfolio, resume, and technical review**

---

## 🚀 Key Features

### 🛒 Shopping Experience

* Add / remove / update products in the shopping cart
* Wishlist (Favorites) system
* Product details page with **color & size selection**
* Display of **similar products**

### 🔍 Product Discovery

* Product search with dropdown results
* Category-based product listing
* Product slider for featured items

### 👤 User Dashboard

* Personal dashboard layout
* My Orders section
* User profile information
* Address management
* Favorites list
* Support section

### 🎨 UI & UX

* Fully responsive design (mobile, tablet, desktop)
* **Three theme modes**: Light / Dark / System
* Clean and modern UI based on **Figma design**

### 📄 Informational Pages

* About Us
* Contact Us
* FAQ (Questions)
* Rules & Regulations
* Return Policy
* 404 – Not Found

---

## 🧠 Technical Highlights

* **React + Vite** for fast development and optimized builds
* **Tailwind CSS** for utility-first styling and responsiveness
* **Context API** for:

  * Authentication state
  * Shopping cart state
  * Favorites management
  * Theme handling
* **Custom Mock API** created and consumed for product data
* Modular folder structure for scalability and maintainability
* Clean separation of pages, components, contexts, and utilities

## ⚙️ Installation & Setup

```bash
# Clone the repository
git clone git@github.com:shaghayegh-b/Fotros.git

# Enter the project directory
cd Fotros

# Install dependencies
npm install

# Run the project locally
npm run dev
```

The app will be available at:

```
http://localhost:5173
```
